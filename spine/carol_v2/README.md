## 開啟

雙擊 `start_preview.bat`（http://localhost:8081/index.html）。直接用 `file://` 開啟，瀏覽器會擋掉模型讀取，畫面只會停在轉圈。

## 重建

```bash
python psd-create/src/spine/make_carol2_spine.py
```

會重新產生 `carol_v2.json / .atlas / .png` 和 `images/`（Spine Editor 匯入用的單張部件）。

## 做法

- **50 個部件全部是蒙皮網格**：上臂–前臂–手套、大腿–小腿–靴子各自共用同一條沿關節的權重，彎曲不會裂開。
  袖口上緣固定在肩膀（像布料拉伸），靴子掛在獨立的 `foot_*` 骨頭上，所以跳起蹲下時腳不會滑。
- **轉頭**：沿用 Inochi2D 版（`make_carol2_puppet.py`）的九軸球面變形，±15° / ±10°，深度表相同；頭整體也往轉的方向位移。雙馬尾跟著綁點走，越往髮尾越少。
- **物理**：雙馬尾（各 6 節）、瀏海、側髮、葉子、呆毛、裙擺、領帶，用彈簧模擬（依身體實際加速度與頭的轉動）烘成關鍵影格，並加上 tanh 軟上限。
  每個動作模擬三圈取最後一圈，所以循環接縫為 0。
- **表情**：`閉眼_*` 的 ^ 笑眼眨眼、`嘴_啊 / 嘴_喔` D 形嘴從上緣撐開、眼神、眉毛。
- **揮手（2026-10-12 重做）**：舊的 舉1／舉2 一張跳約 160°，看起來很不自然，已不用。改成五張原畫一路接過去：
  垂手（PSD）→ out1 手往外擺、手在腰側 → out15 前臂水平 → out2 前臂朝上 → 揮（PSD），每一步約 60°。
  三張中間圖是 Gemini 對齊改圖（`psd-create/src/claude5.5_live2d/prompts/carol2_out{1,15,2}_L.txt`），
  用 `carol2_arms_inbetween.py` 切出 `images/carol2/arm_out*_L.png`（Spine 直接讀，沒有寫進 PSD）。
  每張圖都有自己的肩／肘／腕骨頭，動畫跑一條「虛擬手臂」路徑（肩膀位置、三段角度、長度在各張圖之間內插），
  畫面上的圖會彎到同一個姿勢，所以換圖瞬間前後兩張的輪廓重合（match cut），再用約 2 格淡入蓋過接縫。
  揮動本身是「揮」這張圖的網格彎曲，抵達時肩膀有一點過衝再回穩。

## 動作

| 名稱 | 內容 |
| --- | --- |
| `idle` | 呼吸、身體微晃、眨眼（含連眨） |
| `talk` | 說故事：啊／喔口型、右手手勢、轉頭點頭、挑眉 |
| `wave` | 五張原畫連續舉手 → 揮手（笑眼、張嘴）→ 放下 |
| `happy` | 開心跳兩下（腳離地）、雙手張開 |
| `look_around` | 看左、看右、往上看「喔？」 |
| `nod` | 嗯嗯點頭，接著說「好～」 |
| `surprise` | 嚇一跳：彈起、張大眼、喔嘴、雙手張開 |
